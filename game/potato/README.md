# 감자 언덕 (Potato Hollow)

Don't Starve 풍 잉크 그래픽의 아기자기한 **감자 농사 게임**.
굵고 삐뚠 잉크 외곽선의 2D 종이 인형들이 기울어진 3D 들판에 서 있고(빌보드),
걸어 다니면 시차가 생겨 입체로 읽힙니다. 의존성 0, 빌드 0, 이미지 에셋 0 —
모든 그림은 시작할 때 코드로 구워냅니다.

## 실행

```bash
npm run game          # http://127.0.0.1:4173/potato/
```

## 노는 법

밭 갈기 → 씨감자 심기 → 물 주기 → (새싹 → 잎덤불 → 감자꽃 → 수확기) → 캐기 → 가게에 팔기.

- **WASD** 이동 · **F/Space** 상황에 맞는 농사일 · **Q E / 드래그** 카메라 회전
- 물은 우물에서 다시 받는다. 물이 마르면 성장이 멈추고, 오래 방치하면 시든다
- 비 오는 날은 하늘이 물을 준다
- 2일째부터 **까마귀**가 다 큰 감자를 노린다 — 가까이 가서 쫓거나 허수아비를 사자
- 가게: 씨감자 · 거름(성장 30%↑, 수확 +2) · 큰 물뿌리개 · 허수아비 · 땅 넓히기(+8칸)
- 드물게 **금감자**(15동전)가 나온다. 진행은 `localStorage` 에 자동 저장

## 돈스타브 무드를 내는 것들

- 굵은 잉크 외곽선 + 2차 패스(`core/sketch.js`) · 손그림 지터를 시드로 고정해 선이 안 끓음
- `core/theme.js` 의 tone() 관문에서 모든 채색을 저채도·따뜻한 쪽으로 눌러 "빛바랜 그림책" 톤 통일
- 뒤틀린 S자 줄기의 나무(`twistedTrunk`) · 캐노피 소용돌이 선 · 끝이 말린 곱슬잎(`curlyLeaf`)
- 강한 비네트 + 양피지 종이 질감 곱하기 · 지평선의 어두운 침엽수 실루엣
- 낮→석양→밤 하늘 그라디언트와 밤 멀티플라이, 비 오는 날 무드

## 구조

```
potato/
  index.html, style.css
  src/
    core/    rng · sketch(잉크 드로잉·베이킹) · camera(3D 투영) · input · theme(DS 톤)
    art/     palette · chars(농부 콩 + 괭이/물뿌리개 포즈) · plants(성장 5단계) · props(나무·헛간·우물·가게…) · critters(까마귀·나비)
    world/   farm(밭 상태 기계 · 월드 배치)
    ui/      hud(손그림 HUD · 상점)
    main.js  씬 렌더러(깊이 정렬 빌보드) + 게임 루프 + 저장
```
