# 🫘 Bean Hollow — 2D 손그림, 3D 공간

레퍼런스 스케치(콩 캐릭터 / 숲마을 건물 / 나무·풀 시트)를 그대로 옮긴,
**그림은 2D인데 공간은 진짜 3D**인 브라우저 게임입니다.

```bash
npm run game        # http://127.0.0.1:4173
```

의존성 0개 · 빌드 없음 · 이미지 파일 없음. 모든 그림은 실행할 때 캔버스에 절차적으로 그려집니다.

---

## 어떻게 "2D인데 3D"인가

| 요소 | 방식 |
| --- | --- |
| 공간 | 월드 좌표 `(x, y=높이, z)` 를 실제 원근 카메라로 투영 (`core/camera.js`) |
| 그림 | 전부 손그림 2D 스프라이트 — 항상 화면을 바라보는 빌보드 (돈스타브 / 페이퍼마리오 방식) |
| 깊이 | 카메라 시야 깊이(vz)로 매 프레임 정렬, 크기는 `focal / depth` |
| 접지 | 지면 원을 카메라 피치만큼 눌러 만든 타원 그림자 |
| 원근 | 길바닥 돌·연못·흙자국은 월드 좌표 폴리곤을 그대로 투영한 바닥 데칼 |
| 공기 | 거리별 페이드 + 하늘/능선 시차 + 앞을 가리는 나무 반투명 처리 |
| 부피 | 건물 그림 자체를 3/4 시점(정면+측면+지붕)으로 그려 스프라이트에 부피감 부여 |

카메라를 좌우로 돌리면(Q/E, 마우스 드래그) 앞뒤 물체가 서로 다른 속도로 흐르면서
평면 그림들이 입체 공간에 서 있다는 게 드러납니다.

## 놀거리

- **등불 축제** — 숲에 흩어진 등불 5개를 찾아 마을 문(Gate)에 걸면 밤이 내리고 축제가 시작됩니다.
  아직 안 주운 등불은 근처에 가면 반짝임을 흘립니다.
- **도토리 12개** — 지나가기만 해도 주워집니다.
- **주민 8명 + 숲 친구 11마리** — 퀘스트 진행도에 따라 대사가 바뀝니다.
- 연못에 들어가면 느려지고 물이 튑니다. 달리면 흙먼지가 납니다.

## 손그림 렌더링

선은 매 프레임 다시 그리지 않습니다. 시작할 때 시드 고정 난수로 오프스크린 캔버스에
한 번만 구워 두기 때문에(`core/sketch.js` 의 `bake`) 선이 프레임마다 요동치지 않고,
드로우콜도 `drawImage` 한 번으로 끝납니다.

- `shape()` — 흔들린 선 2겹 + 라인과 살짝 어긋난 채색 (그림책 느낌)
- `corner` 옵션 — 0이면 각진 지붕/텐트, 0.5면 둥근 잎덩어리
- `hatch()` / `stipple()` — 해칭·점묘 음영
- 종이결과 비네트는 한 장으로 미리 합성해 매 프레임 1회 `drawImage`

## 파일

```
game/
  index.html, style.css
  src/
    core/     rng · sketch(잉크 프리미티브/베이킹) · camera(3D 투영) · input
    art/      palette · bean(콩 캐릭터) · nature(나무·풀·바위) · village(건물) · critters
    world/    assets(전부 굽기) · world(마을 배치)
    render/   scene(하늘·지면·데칼·정렬·그림자·조명·종이질감)
    game/     player · npc · quest
    ui/       hud(손그림 UI·대화창)
    main.js   루프와 연결
```

## 성능 메모

- 표시 거리 50유닛, 잔풀류는 24유닛, 화면에서 3px 미만이면 생략
- 그라디언트·종이 오버레이 캐시, 그림자는 반경 2.2px 미만이면 생략
- 헤드리스 소프트웨어 렌더링(SwiftShader)에서 ~27fps, 실제 GPU에서는 60fps 여유
