# 🫘 Bean Hollow — 종이 캐릭터가 사는 3D 숲마을

레퍼런스 스케치(콩 캐릭터 / 숲마을 건물 / 나무·풀 시트)를 바탕으로 만든 브라우저 게임.

- **캐릭터는 2D** — 손그림 종이 인형처럼 화면을 향해 서 있는 빌보드 스프라이트
- **그 외 전부 3D** — 건물·나무·바위·소품은 그림을 붙인 게 아니라 **저폴리 폴리곤 메시**로 새로 만들었습니다.
  스케치 느낌은 **툰 셰이딩 + 잉크 외곽선(실루엣·꺾인 모서리)** 으로 냅니다.
- **그림 스타일 2종** — `컬러`(수채 그림책) / `기본`(색칠 안 한 선화). 타이틀·일시정지 화면에서 고르거나 `C` 키로 바로 전환됩니다.

```bash
npm run game        # http://127.0.0.1:4173
```

의존성 0개 · 빌드 없음 · 이미지 파일 없음. 지오메트리도 스프라이트도 실행할 때 코드로 만들어집니다.

## 3D 파이프라인

| 단계 | 하는 일 |
| --- | --- |
| `core/mesh.js` | 상자·박공지붕·원기둥·원뿔·혹 달린 구·압출·판때기 프리미티브. 모델 원점은 "땅에 닿는 바닥 중앙", 단위는 실제 월드 단위(콩 키 1.5) |
| `art3d/village.js` | 오두막·집·상점 좌판·풍차·망루·천막·마을 대문·우물·돌다리·폐허 아치·울타리·가로등·간판·통·상자·수레·모닥불 |
| `art3d/nature.js` | 침엽수·활엽수·수양버들·고목·덤불·바위·그루터기·통나무·버섯·풀·꽃·부들·묘목·도토리·등불 |
| `art3d/props.js` | (Sheet 4) 자루·양동이·탁자·의자·통나무벤치·등받이벤치·보물상자·바구니·항아리 4종·외바퀴수레·손수레·포장마차·도르래 우물·주막 간판·등피 등잔·우편함·새집·장작받침 |
| `art3d/decor.js` | (Sheet 7) 분수·석상·게시판·돌담·밧줄/철제/사슬 울타리·나무대문·밭문·널문·돌아치·가랜드·깃발·기둥사슬·화분 · (지형 시트) 선돌·돌무더기·흙더미·동굴 입구·절개면·징검돌 |
| `world/terrain.js` | 높이 함수 기반 구릉 지형. 카메라를 따라다니는 클립맵(가까울수록 촘촘)으로 매 프레임 폴리곤을 깝니다 |
| `render/mesh3d.js` | 인스턴스화(정점·노멀·툰 색 선계산) → 백페이스 컬링 → 면 깊이 정렬 → 채색 → 잉크 선 |
| 임포스터 | 같은 카메라 각도로 미리 렌더한 스프라이트. 26유닛 밖은 이걸로 그려 폴리곤 수를 줄입니다 |

### 땅과 오브젝트를 한 덩어리로 보이게 하는 장치

- **땅이 진짜 3D** — 나무·건물·캐릭터·수집품·파티클이 전부 `heightAt(x,z)` 위에 앉고, 플레이어는 경사를 따라 걷습니다
- **연못은 지형이 파인 웅덩이** — 수면 폴리곤은 "지형 높이 = 수면"인 지점을 각도별로 이진 탐색해 만든 물가 선에 맞춰 잘립니다. 물가 모래도 거리 대신 수면과의 높이차로 칠합니다
- **흙길은 지형에 붙는 리본 데칼** + 디딤돌, 광장은 흙 원반
- **밑동 처리** — 나무마다 뿌리를 깔고, 나무·건물 둘레에 잡초·버섯·자갈을 군집으로 심어 접지선을 흐립니다
- **2중 그림자** — 좁고 진한 그림자 + 넓고 옅은 그림자를 겹쳐 물체가 땅에 놓인 느낌
- **군락 배치** — 잔풀·꽃은 균일 난수가 아니라 170~260개의 군락 중심 주변에 모여 자랍니다
- **낙엽·자갈 부스러기** 데칼을 큰 물체 주변에 흩뿌립니다

### 그림 스타일 전환

`core/theme.js` 한 곳에서 색이 지나가는 길목을 잡습니다.

| 대상 | 컬러 | 기본(선화) | 발헤임 |
| --- | --- | --- | --- |
| 2D 손그림 채색 | 원색 | `shape()` 에서 종이톤으로 치환 | 저채도 톤(캐릭터는 원색 유지) |
| 3D 면 | 툰 4단 밴딩 | 명도만 남긴 아주 옅은 회색 4단 | 잉크선 없음 · 따뜻한 태양+차가운 그늘 램프 |
| 지형 | 두 풀색 보간 | 기울기만 옅은 회색으로 | 이끼빛 저채도 + 거리 안개 |
| 하늘·구름·해달·능선 | 시간대 색 | 흰 종이 + 회색 선 | 저채도 하늘 · 이중 침엽수 능선 · 지평선 안개띠 · 해 글로우 |
| 물·불빛·파티클 | 색 | 무채색 | 어두운 청록 물 · 따뜻한 불빛 |
| 화면 오버레이 | 종이결 + 비네트 | 종이결 + 비네트 | 필름 그레인 + 차가운 비네트 + 땅안개·높이안개 |

캐릭터 스프라이트는 두 벌(컬러/선화)을 시작할 때 굽고(발헤임은 컬러 캐릭터를 그대로 씁니다 —
"2D 종이 캐릭터"는 스타일과 무관하게 유지), 3D 인스턴스는 `Theme.version` 이 바뀌면
자동으로 다시 굽습니다. 원경 임포스터는 선화/발헤임으로 처음 바꿀 때 한 번에 구워 둡니다(약 0.5초).
선택한 스타일은 `localStorage` 에 저장되고, 저장이 없으면 발헤임이 기본입니다.

### 잉크 선을 3D에서 뽑아내는 법

1. 프리미티브마다 정점을 새로 만들기 때문에 **위치 기준으로 정점을 용접**해 면끼리의 인접 정보를 만듭니다.
2. 매 프레임 각 모서리에서 양쪽 면의 앞/뒤를 검사해
   - 한쪽만 앞면 → **실루엣**
   - 둘 다 앞면이고 많이 꺾임 → **크리스**(지붕 용마루, 상자 모서리)
   - 둥근 면끼리(구·원기둥) → 선 없음
3. 선은 그 모서리를 공유하는 면 중 **가장 가까운 면**에 맡겨서, 면을 칠한 직후에 긋습니다.
   덕분에 뒤에 가린 선이 앞면에 덮여 사라집니다(간이 히든라인 제거).
4. 흔들림은 모서리 해시로 고정 — 카메라가 움직여도 선이 요동치지 않습니다.

### 그 밖의 입체 장치

- 지면의 길·연못·흙자국은 월드 좌표 폴리곤을 매 프레임 투영하는 바닥 데칼
- 카메라 피치만큼 눌린 타원 접지 그림자(모델 경계상자에서 반경 계산)
- 거리 페이드, 하늘/원경 능선 시차, 밤 색보정 + 광원 글로우
- 플레이어를 가린 앞쪽 물체는 반투명, 카메라 코앞이면 아예 사라짐

## 놀거리

- **등불 축제** — 숲에 흩어진 등불 5개를 찾아 마을 문(Gate)에 걸면 밤이 내리고 축제가 시작됩니다.
  아직 안 주운 등불은 가까이 가면 반짝임을 흘립니다.
- **도토리 12개** — 지나가기만 해도 주워집니다.
- **주민 8명 + 숲 친구 11마리** — 퀘스트 진행도에 따라 대사가 바뀝니다.
- 연못에 들어가면 허리까지 잠기고 느려집니다. 달리면 흙먼지가 납니다.
- 마을에는 분수·석상·게시판·장터 탁자·빨랫줄·텃밭·장작더미가 있고, 숲에는 선돌 무리·돌 아치·동굴 입구가 숨어 있습니다.


## 성능 메모

- 26유닛 안쪽만 실제 폴리곤, 바깥은 임포스터 / 표시 거리 50유닛 / 잔풀은 18유닛
- 지형은 3단 클립맵(1.7 / 5.5 / 14유닛 셀)이고 높이값은 캐시, 데칼 높이는 최초 1회만 계산
- 화면에서 3px 미만이면 생략, 그림자는 반경 2.2px 미만이면 생략
- 정점 투영·면 정렬은 인스턴스마다 재사용 버퍼 사용, 조명 색은 인스턴스 생성 때 1회 계산
- 헤드리스 소프트웨어 렌더링(SwiftShader)에서 ~29fps, 실제 GPU에서는 60fps 여유
