# 🫘 Bean Hollow — 종이 캐릭터가 사는 3D 숲마을

레퍼런스 스케치(콩 캐릭터 / 숲마을 건물 / 나무·풀 시트)를 바탕으로 만든 브라우저 게임.

- **캐릭터는 2D** — 손그림 종이 인형처럼 화면을 향해 서 있는 빌보드 스프라이트
- **그 외 전부 3D** — 건물·나무·바위·소품은 그림을 붙인 게 아니라 **저폴리 폴리곤 메시**로 새로 만들었습니다.
  스케치 느낌은 **툰 셰이딩 + 잉크 외곽선(실루엣·꺾인 모서리)** 으로 냅니다.

```bash
npm run game        # http://127.0.0.1:4173
```

의존성 0개 · 빌드 없음 · 이미지 파일 없음. 지오메트리도 스프라이트도 실행할 때 코드로 만들어집니다.

---

## 3D 파이프라인

| 단계 | 하는 일 |
| --- | --- |
| `core/mesh.js` | 상자·박공지붕·원기둥·원뿔·혹 달린 구·압출·판때기 프리미티브. 모델 원점은 "땅에 닿는 바닥 중앙", 단위는 실제 월드 단위(콩 키 1.5) |
| `art3d/village.js` | 오두막·집·상점 좌판·풍차·망루·천막·마을 대문·우물·돌다리·폐허 아치·울타리·가로등·간판·통·상자·수레·모닥불 |
| `art3d/nature.js` | 침엽수·활엽수·수양버들·고목·덤불·바위·그루터기·통나무·버섯·풀·꽃·부들·묘목·도토리·등불 |
| `render/mesh3d.js` | 인스턴스화(정점·노멀·툰 색 선계산) → 백페이스 컬링 → 면 깊이 정렬 → 채색 → 잉크 선 |
| 임포스터 | 같은 카메라 각도로 미리 렌더한 스프라이트. 26유닛 밖은 이걸로 그려 폴리곤 수를 줄입니다 |

### 잉크 선을 3D에서 뽑아내는 법

1. 프리미티브마다 정점을 새로 만들기 때문에 **위치 기준으로 정점을 용접**해 면끼리의 인접 정보를 만듭니다.
2. 매 프레임 각 모서리에서 양쪽 면의 앞/뒤를 검사해
   - 한쪽만 앞면 → **실루엣**
   - 둘 다 앞면이고 많이 꺾임 → **크리스**(지붕 용마루, 상자 모서리)
   - 둥근 면끼리(구·원기둥) → 선 없음
3. 선은 그 모서리를 공유하는 면 중 **가장 가까운 면**에 맡겨서, 면을 칠한 직후에 긋습니다.
   덕분에 뒤에 가린 선이 앞면에 덮여 사라집니다(간이 히든라인 제거).
4. 흔들림은 모서리 해시로 고정 — 카메라가 움직여도 선이 요동치지 않습니다.

### 그 밖의 입체 장치

- 지면의 길·연못·흙자국은 월드 좌표 폴리곤을 매 프레임 투영하는 바닥 데칼
- 카메라 피치만큼 눌린 타원 접지 그림자(모델 경계상자에서 반경 계산)
- 거리 페이드, 하늘/원경 능선 시차, 밤 색보정 + 광원 글로우
- 플레이어를 가린 앞쪽 물체는 반투명, 카메라 코앞이면 아예 사라짐

## 놀거리

- **등불 축제** — 숲에 흩어진 등불 5개를 찾아 마을 문(Gate)에 걸면 밤이 내리고 축제가 시작됩니다.
  아직 안 주운 등불은 가까이 가면 반짝임을 흘립니다.
- **도토리 12개** — 지나가기만 해도 주워집니다.
- **주민 8명 + 숲 친구 11마리** — 퀘스트 진행도에 따라 대사가 바뀝니다.
- 연못에 들어가면 느려지고 물이 튑니다. 달리면 흙먼지가 납니다.

## 파일

```
game/
  index.html, style.css
  src/
    core/     rng · sketch(2D 잉크·스프라이트 베이킹) · mesh(3D 프리미티브) · camera · input
    art/      palette · bean(콩 캐릭터 2D) · critters(숲 친구 2D) · backdrop(하늘)
    art3d/    village(건물 3D) · nature(자연물 3D)
    world/    assets(모델·스프라이트·임포스터 굽기) · world(마을 배치)
    render/   mesh3d(툰+잉크 3D 렌더러) · scene(하늘·지면·정렬·그림자·조명·종이질감)
    game/     player · npc · quest
    ui/       hud(손그림 UI·대화창)
    main.js   루프와 연결
```

## 성능 메모

- 26유닛 안쪽만 실제 폴리곤, 바깥은 임포스터 / 표시 거리 50유닛 / 잔풀은 22유닛
- 화면에서 3px 미만이면 생략, 그림자는 반경 2.2px 미만이면 생략
- 정점 투영·면 정렬은 인스턴스마다 재사용 버퍼 사용, 조명 색은 인스턴스 생성 때 1회 계산
- 헤드리스 소프트웨어 렌더링(SwiftShader)에서 ~29fps, 실제 GPU에서는 60fps 여유
